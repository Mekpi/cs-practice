Создали пустой репозиторий cs-practice.
Рабочая папка - папка, с которой мы работаем. Там храняться изменения пока не зафиксированные гитом.
Индекс - область, в которой храняться изменения, добавленные туда командой git add.
Коммит - операция фиксирования изменений, которые находятся в индексе, в истории.
Git - это программа на компьютере для отслеживания изменений и котроля версий.
GitHub же - это облачный сервис, на котором удобно хранить все изменения для общего доступа.
